# Usage-saving workflow

Use these independent skills where relevant and available. The user's request, deadlines, platform capabilities and authorization determine which steps apply; the skills are not dependencies.

1. **Start:** Check relevant existing work and define the actual outcome. Use `reuse-before-research` and `usage-saving` if available.
2. **Work:** Read enough to answer reliably, batch independent calls and wait for meaningful events. Use `cheap-delegation` when independent, authorized work helps; use `lean-chats` for a handover when useful.
3. **Repeat:** For an actual recurring need, use `frugal-routines` to compare a supported event trigger or schedule against deadlines, time zone and delivery preferences.
4. **Finish:** Record durable findings or a handover when useful and in scope. Changes to memory, files or chats follow their own authorization.
5. **Review:** If requested, use `weekly-cleanup-review` to inspect the setup, skip active work and present findings. Backups, changes to routines and external messages need appropriate authorization.

Use actual platform reports for usage and cost. Preserve correctness, required reviews and timely progress updates.
