# Usage Saving

Right-size tasks and reduce unnecessary context, calls and polling while preserving required checks.

## Install

Clone this repository into your agent's skills directory, keeping `SKILL.md` and its supporting files together. For Codex:

```sh
git clone https://github.com/felipepetersmann22-star/usage-saving-skill.git ~/.codex/skills/usage-saving
```

Restart or refresh skill discovery if needed. Other agents may use a different skills directory.

## Use

Use when planning a task or reviewing an assistant setup for unnecessary usage. This skill is an entry point to the wider set. The related skills named in `SKILL.md` are separate repositories and are optional unless a workflow calls for them. The original [workflow](WORKFLOW.md) describes how they fit together.
